ign1t10n

This installs F1R3Gaze (if needed) and ign1t10n, which runs a private F1R3FLY shard on this Mac: a bootstrap node, validators, an observer and, optionally, Embers, all reachable only from this Mac.

When installation finishes, ign1t10n opens and asks how many validators to run. Setting up takes a few minutes.

Requires a Mac with Apple silicon and macOS 13 or later.
